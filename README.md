# 꾹 (gguck)

> 한 줄로 말하면 일정이 되는 캘린더 — "다음주 금요일 8시 종숲 ㄱ" 같은 카톡 말투 문장을 그대로 붙여넣으면 AI가 알아서 날짜·시간·장소·카테고리를 뽑아 등록합니다.

**실행:** https://gguck-flame.vercel.app

## 무엇을 하는 앱인가요

"일정 비서" 입력창에 자연스러운 문장을 쓰면 일정이 됩니다.

```
내일 오후 8시 집에서 운동
매주 월수금 오후 8시 운동
3박 4일 부산 여행
종숲 취소
운동 전체 반복 취소
```

- **등록/취소를 한 문장으로** — 로컬 규칙 파서가 먼저 시도하고, 복잡한 문장만 Gemini API로 넘어갑니다.
- **개인 장소 사전** — "종숲" 같은 사적인 줄임말은 처음 한 번만 뜻(이름·주소·카테고리)을 물어보고, 다음부터는 자동으로 인식합니다.
- **반복/기간 일정** — 매일·평일·매주·매월 반복, 2박 3일 같은 기간 일정을 지원합니다.
- **규칙 기반 충돌 검사** — "운동 다음 날은 쉬기", "주 3회 이하" 같은 규칙을 자연어로 등록하면, 새 일정이 규칙을 어길 때 대안 시간을 제안합니다.
- **구글 캘린더 연동** — 선택적으로 연결해서 양방향 동기화.
- **일괄 가져오기** — .ics 파일, 근무표 엑셀, 근무표 사진(OCR)에서 일정을 한 번에 추출.
- **공유하기로 바로 등록** — 카톡 등에서 문장을 "공유하기"로 보내면 앱이 자동으로 일정 등록까지 진행.
- **PWA** — 홈 화면에 설치해서 앱처럼 사용 가능.

## 기술 스택

| 영역 | 사용 기술 |
| --- | --- |
| 프론트엔드 | Expo (React Native + React Native Web), TypeScript |
| AI | Google Gemini API (`@google/genai`), 구조화 출력(JSON Schema) |
| 백엔드 | Vercel Serverless Functions, Upstash Redis |
| 연동 | Google Calendar API (OAuth), Web Push |
| 저장 | AsyncStorage (로컬 우선, 서버 DB 없음) |
| 테스트 | Node.js 내장 테스트 러너 (`node --test`), 70개 |
| 배포 | Vercel |

## 아키텍처 하이라이트

자세한 설계 배경과 문제 해결 과정은 **[DEVLOG.md](./DEVLOG.md)** 에 기록해뒀습니다. 요약하면:

1. **2단계 해석 구조** — 모든 문장을 AI로 보내지 않습니다. 정규식 기반 로컬 파서(`utils/scheduler/`)가 먼저 시도하고, 실패한 문장만 Gemini로 넘어갑니다. API 비용·지연을 줄이고, 키가 없어도 기본 기능이 동작합니다.
2. **개인 사전 + 카테고리 자동 학습** — 사적인 줄임말은 검색으로도 풀 수 없는 문제라고 판단, "모르면 한 번 묻고 다음부터 기억"하는 방식으로 설계했습니다.
3. **AI 응답 검증 후처리** — 구조화 출력을 쓰더라도 모델이 가끔 없는 사실을 지어내거나(할루시네이션) 명확한 걸 애매하다고 판단합니다. 서버 단에서 응답을 한 번 더 검증·보정합니다(`utils/placePolicy.ts`).

## 로컬 실행

Node.js 22.13 이상이 필요합니다(Expo SDK 57 최소 요구사항).

```sh
npm install
npm run web
```

AI 해석·구글 연동까지 포함해 전체 기능을 쓰려면 `.env.example`을 참고해 환경변수를 설정하고 Vercel로 배포하세요(`npm run web`은 Expo 화면만 띄우고, `api/` 서버리스 함수는 함께 실행되지 않습니다).

```sh
npm test         # 테스트 70개 (API 키 불필요)
npm run typecheck
npm run format    # Prettier 적용
npm run build     # Vercel 배포용 빌드
```

## 알려진 제약

- 일정/규칙은 브라우저 로컬 저장소에 있습니다. 기기 간 동기화나 서버 DB는 아직 없습니다(구글 캘린더 연동 시 그쪽으로는 동기화됨).
- 충돌 검사는 이 앱에 저장된 일정만 대상으로 합니다. 구글 캘린더의 기존 일정까지 불러와 비교하진 않습니다.
- Google 연동은 현재 단일 사용자(`userId: local`) 구조입니다. 여러 사용자가 쓰는 공개 서비스로 확장하려면 사용자별 인증 세션과 서버 권한 검사가 필요합니다.
- 로컬 파서는 모든 한국어 문장을 이해하지 않습니다 — 복잡하거나 애매한 문장은 Gemini API 호출이 필요합니다.
- Gemini 무료 티어라 가끔 과부하(503) 응답이 옵니다. 클라이언트에서 자동 재시도하지만 완전히 없앨 순 없습니다.
